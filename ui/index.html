How the phase is derivedCharacter counts to a signed field
01 / Count characters
The adapter applies Unicode NFC normalization and counts code points. Case and whitespace remain significant; order is discarded. Empty text and a single distinct character have entropy zero.
pᵢ = countᵢ / n
H = −Σ pᵢ log₂(pᵢ)
02 / Normalize by length
n is the normalized phrase length. This length-based bridge makes repetition affect the phase even when character frequencies are unchanged.
normalized = clamp(H / log₂(n), 0, 1)
φ = π · normalized
For n ≤ 1, normalized entropy and phase are both zero.
03 / Sample the field
The supplied model is a signed symbolic field. With u, v, y and t held constant, the workbench evaluates 129 x positions from −π to π.
value(x) = hypot(u, v) · sin(xy + t + φ)
Character frequency describes this text sample; it does not measure meaning or cryptographic strength.
